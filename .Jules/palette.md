# Palette Journal - Bay Builders

## 2025-08-06 - Interactive Contact Links
**Learning:** In luxury brand dark-theme websites, phone numbers are often left as plain text which reduces mobile user engagement and accessibility. Making them interactive with `tel:` tags and using a `.contact-link` class ensures seamless hand-off to dialers.
**Action:** Use interactive anchor tags with standard class `contact-link` and styles `color: inherit; text-decoration: underline;` to make phone numbers discoverable without altering the brand's aesthetic.
