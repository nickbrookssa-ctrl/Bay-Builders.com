# Palette Journal

## 2025-05-18 - Interactive Phone Numbers for Contact
**Learning:** Plain text phone numbers on landing pages hinder user experience, especially on mobile devices where direct tap-to-call functionality is expected. Using `tel:` links with `color: inherit` maintains visual consistency while drastically improving actionability and keyboard accessibility.
**Action:** Always wrap contact phone numbers in `<a href="tel:...">` with standard link styling and focus states.
