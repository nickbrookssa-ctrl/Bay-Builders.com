## 2025-07-17 - Preloading High-Volume Image Sequences Safely and Accessibly
**Learning:** High-fidelity interactive websites utilizing scroll-driven canvas animations often preload hundreds of heavy images (e.g., ~240 frames). This creates UX 'dead zones' of blank black screens that frustrate users. To solve this, a minimalist branded progress indicator must be introduced. By assigning image load event handlers before setting the `src` attribute, we prevent race conditions with cached images. Standardizing interactive loader lifecycles via `.remove()` prevents DOM clutter and satisfies automated checks.
**Action:** When working with canvas-based sequences, always implement a minimalist loading bar with `role="progressbar"`, `aria-label`, and dynamically update the properties from robust handlers (`onload`/`onerror`/`onabort`), ensuring smooth state transitions synchronized with JS-based DOM removal.
