# Palette's Journal

## 2026-06-06 - Interactive Contact Links
**Learning:** For users accessing high-end service websites on mobile devices, phone numbers presented as static text are dead ends. Wrapping phone numbers in a tel: hyperlink with a clear keyboard focus state dramatically improves physical accessibility and interaction efficiency. Styling the link with color: inherit ensures design tokens are respected and prevents contrast issues on dark themes.
**Action:** Always wrap standard phone numbers in tel: links using a dedicated class to preserve styling structure, ensuring accessibility is preserved and keyboard navigation is enabled.
