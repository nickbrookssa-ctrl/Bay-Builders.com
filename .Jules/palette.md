## 2025-08-13 - Branded Asset Loader & Canvas Accessibility
**Learning:** High-asset sequence sites (like luxury construction pages with 240+ frames) present visual "dead zones" during initial preloading. Providing an elegant loader with dynamic, ARIA-compliant progress updates prevents users from seeing a blank screen while loading frames. By hiding three-dimensional backdrop layers via `aria-hidden="true"` and marking up interactive or informational canvases with proper ARIA attributes, the AOM remains clean and useful for screen reader users.
**Action:** Always wrap heavy assets in robust preloading Promise chains that attach event handlers (`onload`, `onerror`, `onabort`) before setting the source to prevent race conditions. Pair this with a self-cleaning (`element.remove()`), high-contrast UI loader synced with CSS transitions.
